# Delfine India Technology Website

A dynamic and responsive company website for Delfine India Technology, built using React.js, Java Spring Boot, and MySQL.

## Technology Stack

- Frontend: React.js, JavaScript, HTML, CSS
- Backend: Java, Spring Boot, REST APIs
- Database: MySQL
- ORM: Hibernate, Spring Data JPA
- Security: Spring Security, JWT
- Version Control: Git and GitHub
- Containerization: Docker
- CI/CD: GitHub Actions

## Project Modules

- Home
- About Us
- Services
- Projects / Portfolio
- Testimonials
- Contact Us
- Admin Dashboard
- Authentication and Authorization
